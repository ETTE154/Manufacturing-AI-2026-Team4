현재 전기품질 이상 후보 진단 실험

XGBoost 분류, 규칙 변수 제외 전달 테스트, 재구성 Autoencoder를 시간 순서로 비교했습니다.

실제 고장 라벨이 없는 상태의 실험

아래 점수는 고장 진단 정확도가 아닙니다. 가이드는 삽입 이상치가 있다고 설명하지만 위치·정답 라벨은 제공하지 않습니다. 상전압 205–225V 밖 / 상역률 80–100% 밖 등의 탐색 규칙을 약한 후보 라벨로 사용했습니다. 이는 고장·삽입 이상치의 확정 판정이 아닙니다.

각 관측의 센서값으로 현재 이상 후보 여부를 판별하며 장래 고장 발생을 예측하는 작업이 아닙니다. 5월 전력량 정답은 이 실험에 사용하지 않았습니다.

균등 표본과 시간 순서 검증

원시 33,696,013행을 한 번 읽고, 각 모듈×완전시간의 720개 5초 슬롯에서 무작위 4개를 고정 seed로 뽑았습니다. 총 187,200행이며 이상 후보를 추가 추출하지 않았습니다. 모든 완전시간 관측의 포함 확률은 4/720으로 동일합니다. 4/30의 부분시간 1행은 제외했고 localtime을 사용했습니다.

재구성 오차와 학습 가정

전체 학습 AE는 12–2월의 모든 관측을 사용해 scaler와 재구성 모델을 비지도 학습했습니다. 약한 정상 proxy AE는 같은 학습 구간에서 규칙 후보를 제외하고 학습한 준지도 실험입니다. 두 모델의 기본 경보 임계값은 3월의 약한 정상으로 보정하므로 경보 시스템 전체를 완전한 비지도라고 부를 수 없습니다.

전체 학습 AE에 대해서는 모든 3월 관측으로 임계값을 계산하는 완전 비지도 대안도 JSON에 별도로 기록했습니다. 이는 양성 라벨로 임계값을 선택하지 않는 비교이며 점수 확인 후 모델 선택에 사용하는 값이 아닙니다.

프로젝트 적용 판단

  • 규칙 모사의 높은 점수는 규칙을 코드로 직접 구현하는 방식과 함께 평가해야 합니다. 동일 규칙이 목적이라면 복잡한 분류기의 실익이 제한적입니다.
  • AE 점수는 약한 센서 규칙과 일치하지 않는 지점도 탐색하게 합니다. 그 점을 곧바로 실제 고장이나 오탐으로 확정하지 말고 원시 센서 시계열과 현장 정보를 검토해야 합니다.
  • 샘플 경보 행 수는 전체 원시 데이터의 고장 사건 수가 아닙니다. 실제 운영에서는 지속시간·설비·유형별 묶음과 재알림 제한이 필요합니다.
  • 다음 검증은 점검·교체·정지 이력과 삽입 이상치 위치를 확보하여 실제 고장/정상 라벨을 만들고, 시간 순서 테스트와 미관측 설비 테스트를 분리하는 것입니다.

표본은 드문 짧은 이상을 놓칠 수 있고, 알려진 13개 설비에 대한 월별 검증은 새로운 설비로의 일반화를 보장하지 않습니다. 약한 정상 proxy에도 미확인 실제 고장이 남아 있을 수 있습니다.
