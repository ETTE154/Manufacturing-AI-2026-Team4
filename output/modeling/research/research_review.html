전력 시계열 오픈 데이터·예측 연구 조사 및 평가 설계

검토일 2026-10-11 · 산업 데이터 구조, 장기 예측 protocol, 모델 최신성과 실험 가능성을 나누어 확인

판단과 적용 범위

  • 설비별 3상 전력·전압·전류와 약 5초 계측이라는 데이터 구조는 HIPE가 가장 가깝다. 2026년 SPARK 확장 데이터도 매우 유사하지만 데이터 기술 논문이며 예측 모델의 공통 SOTA 순위를 제시하지 않는다.
  • 확인한 HIPE 예측 실험은 10/30분 또는 1 step~15시간 앞의 단기 예측이다. 1개월 앞의 이번 평가에는 시간 해상도 ECL 장기 예측 연구의 평가 조건을 함께 참조한다.
  • CPU에서 로컬 학습하는 연구 계열 비교는 PatchTST와 iTransformer를 권한다. 2026년 절대 최고라는 뜻은 아니다. Chronos-2 사전학습 추론을 추가하면 최근 foundation model 계열 비교를 보완할 수 있다.
  • 2026년 8월 TimesFM 3.0의 저자 보고 집계 벤치마크 우세도 확인했다. 이 결과는 HIPE/이 프로젝트/720시간 MAE에서의 우승을 증명하지 않는다.
  • 실제 고장 라벨이 없으므로 지도 분류의 목표는 규칙 기반 이상 후보 구분이며 AE는 비지도 재구성 이상 점수이다. 실제 고장 진단 정확도·재현율을 산출할 근거가 없다.

공식 데이터 기관, 저자 논문, 공식 저장소와 모델카드를 검토했다. 로컬 원본 CSV를 다시 읽지 않았다. 검토한 문헌의 성능을 이 프로젝트의 실험 결과로 간주하지 않는다.

  • scaler와 모델 fit은 해당 origin 직전 train에만 적용; training window의 출력 label이 train cutoff를 넘지 않아야 함
  • 예측은 한 번의 origin에서 745개를 생성; 240개 비점수 bridge를 실제 5월 관측으로 채우지 않음

  • 확정 달력만 future covariate; 미래 실제 센서/날씨/생산량은 origin 당시 확보된 것만 사용
  • 모델·hyperparameter·seed·quantile 선택은 April 검증으로 끝내고 May는 최종 1회 평가
  • 모든 모델은 같은 origin/target/단위/slice 비교. 추가 multivariate 입력과 aggregate-only 입력의 차이를 함께 표시
  • 벤치마크 정규화 MAE와 프로젝트 kWh MAE를 숫자로 직접 비교하지 않음

신호 CV가 낮고 평균 기준선이 강하므로 복잡 모델은 MAE 감소와 실제 실행 시간으로 가치 판단; 모델 이름만으로 성능 향상을 가정하지 않음

분류와 Autoencoder 평가 해석

voltage/PF/unbalance 규칙 기반 이상 후보 state label. 실제 고장 class 아님

proxy label에 대한 precision/recall/F1만 가능; 고장 진단 F1로 명명하지 않음

과거 screened apparently-normal 구간에 scaler/AE fit; validation 재구성 오차 quantile로 threshold 고정. 정상 정답이 검증된 것은 아님

시간순 분할, 설비별 calibration, 후보 이벤트/일·지속시간·점수·proxy rule 일치도 보고. 실제 fault recall/F1와 detection delay는 라벨 수집 전 계산 불가

  • 설비 ID와 voltage/PF 변수가 rule label을 거의 결정하면 분류는 규칙 복제 성능일 수 있음
  • 운영 속도·부하 변화·센서 오류도 이상 점수를 높일 수 있으므로 원인 확인과 실제 유지보수 라벨 필요
  • 합성 고장 주입 실험은 synthetic detection으로 구분하고 실제 진단 성능으로 전환하지 않음
  • NILM 기계 가동 label과 부하 class를 fault label로 해석하지 않음
  • 대상 데이터를 보고 threshold를 반복 조정한 뒤 같은 데이터를 test로 재사용하지 않음
