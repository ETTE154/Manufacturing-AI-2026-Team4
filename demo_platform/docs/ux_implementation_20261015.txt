FactoryLens · UI/UX 개선 적용
2026-10-15

화면 사용 흐름
1. 운영현황의 시연 안내에서 데이터 수집 재생, 원본 이상 후보 검토, 모델 검증 중 하나를 선택합니다.
   학습 시작 시각2024-12-01 00:00:00과 일시정지·20배 기본값은 유지합니다.
   상단 '전체 데이터 수집 재생'을 펼치면 기존 재생·배속·사례 선택을 사용할 수 있습니다.
2. 설비분석은 실시간 관측 / 기간 조회 모드로 구분합니다.
   기간 조회에서는 가용 날짜·집계·센서를 정하고 조회를 눌러 적용합니다.
   변경 중인 초안과 실제 적용 결과는 계속 구분합니다.
3. 고장진단은 대상·후보 시간·저장된 핵심 탐지 근거를 먼저 보여줍니다.
   구간 설정과 상세 모델 점수는 기본적으로 접어 두며 필요할 때 펼칩니다.
   전후 프리셋은 입력 초안만 바꾸고 '범위 적용·재생'으로 실행합니다.
   공통 재생/정지·배속·현재 시각·진행 막대는 하단 센서에서도 사용할 수 있도록 고정합니다.
   다섯 센서는 같은 시각·범위를 공유하며 R/S/T상은 선형·마커로도 구분합니다.
   붉은 영역은 선택 후보 구간, 붉은 점은 후보 시각이며 개별 센서 고장 확정이 아닙니다.
4. 알림 읽음과 담당자 확인(ACK)을 구분합니다.
   담당자 확인 완료는 실제 고장 확정이나 조치 완료를 의미하지 않습니다.
5. 예측·비용은 현재24시간 전망 / 모델 검증 상세 탭으로 구분합니다.
   모델 선택은 고정 평가 비교에만 적용됩니다. 현재 온라인 전망의 모델 교체가 아닙니다.
   모듈별 현재 전망과 전체13모듈의 별도 고정 평가·MAE·R²를 섞지 않습니다.
6. 주간리포트는 현재 조건으로 생성 / 과거 저장본 열람을 구분합니다.
   새 생성의 대상·관측 창·완료 관측 수를 먼저 확인합니다.
   저장본은 실제 대상·관측 기간·생성 시각을 표시하며 현재 조건의 결과로 자동 대체하지 않습니다.
   생성 결과는 생성 당시의 저장 결과이며, 이후 재생 시점이 바뀌어도 자동 갱신되지 않음을 안내합니다.
7. 하단 데이터 검색은 현재 적용 조회 또는 후보 검토 구간의 범위를 표시합니다.
   검색 기준 선택으로 전체 수집 재생 기준으로 전환할 수 있습니다.
   답변에도 실제 대상·배타 종료점·원본 관측 수와 단위를 표시합니다.
   우하단 검색 바로가기는 하단 검색창으로 이동하며 기존 하단 검색 기능을 유지합니다.
8. 서비스 설정은 운영자에게 연결 상태와 가능한 대체 기능을 먼저 안내합니다.
   Webhook·환경변수·인증 진단은 관리자용 접기 영역으로 분리합니다.
   연결 설정 여부와 외부 전송 승인 여부는 계속 별개의 상태입니다.

검색 API 계약
POST /api/chat
context: module_id, cursor_time, scope(replay/archive/diagnosis), source_kind(recorded)
명시 archive/diagnosis 추가: start, end(배타 종료), grain(raw/hour/day/week/month).
diagnosis는 raw로 제한합니다. 원본5초 구간을 시간단위로 잘라 버리지 않습니다.
조회는 실제 적용 응답의 effective_start/effective_end_exclusive를 사용합니다.
모듈·기간·간격·원본 범위를 서버가 검증하며 모듈과 기간은 검색 계획이 덮어쓰지 못합니다.
명시 범위 검색은 local_only 요청 값과 무관하게 서버 내부에서 처리합니다.
합성 시연 구간을 선택했다면 검색은 '합성 변형 이전 원본'임을 표시합니다.
반환: query_scope, row_count, source_observation_count, unit, record_unit, statistics, citations.
해당 짧은 구간만으로 예측 모델 성능을 새로 계산하지 않으며 고정 평가 화면으로 안내합니다.
기본 replay 검색은 기존 승인에 따라 질문·선택 모듈·재생 시각만 GPT로 보낼 수 있습니다.
새 조회 start/end/grain/page는 외부 GPT 요청에 추가하지 않습니다.

가독성과 접근성
차트 범례 문자는 진한 중립색, 상별 선·아이콘은 채널색을 유지합니다.
차트 축·범례12px, 핵심 측정값14px를 사용합니다. 이는 설계 목표이며 전체 접근성 인증은 아닙니다.
모바일 검색 아이콘은 항상 접근 가능한 이름을 가집니다.
닫힌 모바일 메뉴는 inert 처리하고 설정 drawer는 포커스 진입·순환·Escape·복귀를 처리합니다.
설정 drawer의 닫힌 상세 제목(summary)도 Tab 순서에 포함합니다.
모바일 메뉴에서 설정을 열고 닫으면 숨은 메뉴 항목 대신 '메뉴 열기' 버튼으로 포커스를 복귀합니다.
페이지 탭은 키보드 좌우/Home/End와 선택 상태를 제공합니다.
기존 클릭 가능한 모듈 표에는 이름이 있는 키보드 접근 링크를 제공합니다.
후보 상세를 연속 조회하면 마지막 요청의 결과만 표시하고, 닫거나 페이지를 떠난 뒤의 늦은 응답은 무시합니다.
