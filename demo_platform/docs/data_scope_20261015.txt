검토 결과와 변경 이유
1. 현재 재생과 과거 기록을 구분했습니다.
   이전에는12월 시점을 재생해도3월의 저장 알람 수가 현재 이상처럼 보였습니다.
   운영현황은 현재 관측 전력·역률·수신 모듈·3연속 이상 감지 모듈에 집중합니다.
   이번 재생 세션의 알림 수와 현재 감지 상태를 별도로 표시합니다.
   저장 알람은 알림 센터와 고장진단의 '저장된 알림 이력'에서 확인합니다.
   개요의 수신 로그도 현재 세션에서 이 화면이 받은 관측만 보여 줍니다.
   SQLite의 영구 수집 로그와 기존 알람은 삭제하지 않았습니다.

2. 실제로 동작하는 범위 선택만 제공합니다.
   운영현황: 선택 모듈의 최근5분 스트리밍, 과거 조회는 설비분석으로 연결.
   설비분석: 모듈·센서·집계·날짜 선택과 기간 조회.
   예측·비용: 선택 모듈/현재 재생 원점의24시간 예측과 별도 고정 실험 평가.
   고장진단: 전체 원본의 사후 후보와 저장 알림 이력.
   주간리포트: 선택 모듈/현재 재생 시점까지 최근7일 완료 관측.
   이전의 모든 페이지 공통 날짜/집계 컨트롤은 페이지 목적에 맞게 줄였습니다.

3. 조회 설정과 실제 적용된 결과를 분리했습니다.
   조회 성공 때의 모듈·센서·집계·기간을 appliedQuery로 보관합니다.
   설정만 바꾸면 '기간 조회를 눌러 적용' 안내가 나타나며 기존 결과의 설명은 유지합니다.
   과거 조회 후 운영현황으로 돌아가도 과거 KPI와 현재 모듈표가 섞이지 않습니다.
   조회 기록 표는 실제로 조회한 센서 열만 제공합니다. 미조회 항목의 빈 열을 줄였습니다.
   집계의 records/complete를 보존하여 부분 주·월을 명시합니다.

4. 필요한 맥락을 추가하고 비어 있거나 반복되는 정보를 덜었습니다.
   현재 감지의3연속 기준, 이번 재생 알림 수, 실제 적용 기간, 부분 집계 정보를 추가했습니다.
   계산할 수 없는 알고리즘 점수/임계값의 빈 비교 열은 제거했습니다.
   탐지 방식·합성 검증·계측 기준의 긴 설명은 접어서 볼 수 있게 옮겼습니다.
   원본 기록 시각을 중심으로 표시하고 서버 수신 시각은 한국 시각 HH:mm:ss로 줄였습니다.
   전체 모듈 전력은 분전반·개별 설비 중복 계측 가능성이 있는 합계임을 표시합니다.
   역률은 소비량 가중값이 아닌 산술 평균임을 설명합니다.

5. 초기 이력 부족을 데이터0과 구분합니다.
   처음에는 완료된 시간 관측이0개이므로 예측을 생성하지 않습니다.
   '첫 완료 시간 대기'와 완료 관측0시간을 표시하고 금액/전력량을 가짜0으로 채우지 않습니다.
   첫1시간 완료 전 주간리포트 생성 버튼은 비활성화합니다.
   저장 보고서는 실제 모듈·기간·관측시간/168시간과 부분 기간 여부를 표시합니다.
   현재 시점의 예측 카드와 전체13모듈의 고정 실험 MAE를 같은 KPI 묶음으로 표시하지 않습니다.

API
/api/bootstrap.meta.series_availability.by_module[module][grain]
  min_date/max_date, available_dates, first_timestamp/last_timestamp,
  coverage_start/end_exclusive, period_count/complete_period_count,
  부분기간 플래그 및 원본 말단일 관측 수를 실제 원본 bounds·완료 집계에서 계산합니다.
/api/series?range_mode=calendar
  UI 종료일은 다음날00:00 exclusive로 전송하고 말단 부분일만 실제 끝으로 제한합니다.
  선택일이 보유기간 밖이면400, 원본24시간 초과/역순도400입니다.
  명시 timestamp 모드는 엄격하게 범위 밖을 차단하며, 날짜 생략 기본 조회는 가용 범위로 제한합니다.
  effective_start/effective_end_exclusive와 집계 records/complete를 반환합니다.
replay 상태는 session_detection_count/active_detection_module_ids/completed_history_hours를 제공합니다.
