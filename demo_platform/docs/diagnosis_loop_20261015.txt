FactoryLens · 고장진단 구간 반복 재생
2026-10-15

사용 방법
1. 고장진단의 원본 후보 표 또는 저장된 알림 이력에서 '구간 반복 재생'을 누릅니다.
   상세 그래프와 알림 상세의 같은 버튼도 이 플레이어로 연결됩니다.
2. 고장진단 페이지 안에 '고장 구간 반복 재생'이 열리고 자동으로 반복 재생합니다.
   다른 페이지의 알림 상세에서 진입하면 고장진단 페이지의 플레이어가 열립니다.
3. 기본은 후보 첫 관측 60초 전부터 후보 마지막 관측 60초 후까지입니다.
   발생 전/후를 각각 0~1,800초, 5초 단위로 입력하고 '범위 적용·재생'을 누릅니다.
   '전후 1분 / 2분 / 5분' 버튼은 범위를 즉시 적용하고 처음부터 재생합니다.
4. 구간 일시정지/재생, 처음부터 재생, 1·5·20·60배 속도를 사용할 수 있습니다.
   기본 속도는 5배입니다. 진행 막대를 움직이면 그 관측으로 이동하고 일시정지합니다.
5. 전압·전류·역률·유효전력·무효전력 5종을 같은 화면에서 동시에 비교합니다.
   전압/전류/역률은 R/S/T상과 현재 값을 각각 표시합니다. 모든 센서는 하나의
   재생 위치·관측 목록·시간축·현재 시각 점선을 공유하고, 마우스 비교도 연동합니다.
   센서별 고유 단위와 선택 구간의 세로축 범위를 유지해 반복 중 축 흔들림을 줄입니다.
   데스크톱은 3+2개, 태블릿은 2열, 휴대폰은 1열로 배치합니다.
   규칙 6종 중 하나를 선택해 같은 시각의 AI 점수와 비교합니다.
   센서와 규칙/Autoencoder/Isolation Forest는 고정된 구간 시간축을 공유합니다.
   최신 검토 시각을 점선으로, 선택 후보 구간과 임계값 초과를 붉게 표시합니다.
6. 끝 관측까지 표시한 뒤 첫 관측으로 돌아가며 '회차'가 증가합니다.
   닫기 또는 다른 페이지 이동 시 이 구간 재생의 타이머가 해제됩니다.

범위 기준과 데이터
고장 정답 시각이 제공되지 않아 '발생'은 저장된 이상 후보의 관측 구간입니다.
예: 2025-03-13 19:45:05~19:45:15 후보는 기본 범위
19:44:05~19:46:15, 양끝을 포함한 27개의 실제 5초 관측입니다.
연속 후보의 전체 구간을 포함하므로 기본 길이는 120초 + 후보 구간 길이입니다.
전후 모두 0초로 설정해도 후보의 전체 연속 관측을 유지합니다.
보유 원본의 양끝에서는 조회 범위를 자르고 실제 전후 초와 경계 안내를 표시합니다.
범위 밖 값을 보간하거나 없는 센서/AI 점수를 0으로 만들지 않습니다.
합성 시연 알림은 원래 변형 유형과 원래 기준 시각을 유지해 센서를 재현합니다.
원본 기록 시각(localtime)을 사용하며 Unix clock으로 재해석하지 않습니다.

전체 스트리밍과의 관계
구간 재생은 선택 구간을 한 번 조회한 뒤 브라우저 안에서 관측을 순서대로 표시합니다.
상단의 전체 수집 재생 시각/설비/재생 구간/속도는 구간 재생 버튼으로 바뀌지 않습니다.
매 반복에서 수신 로그, 고장 알림, Slack 전송 대기열을 새로 만들지 않습니다.
상단 스트리밍이 별도로 실행 중이면 그 원래 실행에 따른 실제 로그는 계속 수신됩니다.
기존 POST /api/replay jump_event API는 호환을 위해 유지하지만 진단 UI는 호출하지 않습니다.

새 읽기 전용 API
GET /api/diagnosis/{event_id}/replay-window?before_seconds=60&after_seconds=60
원본/현재 occurrence/저장된 알림 ID를 지원합니다. 현재 occurrence가 저장된 알림보다 우선합니다.
응답: event, series, algorithm(규칙6), ai(AE/IF), source_kind, coverage_note, window.
window: start, end_inclusive, end_exclusive, event_start, event_end,
requested_before_seconds, requested_after_seconds, actual_before_seconds,
actual_after_seconds, sampling_seconds(5), point_count, clipped.
입력 오류 400, 없는 후보 404, 점수 모델 미준비 503. 키와 외부 API는 필요하지 않습니다.
