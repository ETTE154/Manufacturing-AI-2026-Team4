FactoryLens UI 행동·가독성 개선 기록
작성일: 2026-10-15 (Asia/Seoul)

반영 범위
- frontend/src/App.jsx, frontend/src/data.js: 실시간 축·세션 처리·이벤트 재생·후보 표시.
- CSS는 별도 담당자가 수정했으며 최종 통합 빌드로 검증했다.
- api.control('jump_event', {event_id})는 기존 api.js 전달 계약을 사용한다.

실시간 차트
- 서버 snapshot.timestamp(실제 표시된 최신 관측)가 오른쪽 끝이다.
- replay.cursor_time은 다음 관측을 가리킬 수 있으므로 축 기준으로 사용하지 않는다.
- 왼쪽은 최신 관측 300초 전, 오른쪽은 최신 관측: 5초 원본의 60간격/최대61끝점.
- 첫 관측만 보유한 경우에도 5분 축을 유지하여 과거 빈 구간을 명료하게 표시한다.
- 60초 간격의 6개 축 눈금과 양 끝 시각을 유지한다.
- 원본의 naive 기록 시각을 숫자축에 인코딩하고 같은 기록 시각으로 표시한다. 브라우저 시간대로 변환하지 않는다.
- session_id가 바뀌면 이전 수신 관측·클라이언트 수신 로그를 비운다. 서버의 영구 로그는 삭제하지 않는다.
- 전역 monotonic sequence가 뒤처진 응답은 무시한다. 새 SSE 연결에서는 서버 재시작에 따른 sequence 초기화를 허용한다.

기간 조회
- 실시간 rolling과 별도 historyMode를 사용한다. 빈 조회 결과도 실시간 관측으로 대체하지 않는다.
- 과거 조회의 전체 관측을 표시하며 이전 240점 제한을 제거했다.
- 실시간 복귀 또는 이벤트 이동 시 과거 필터와 조회 모드를 해제한다.
- 과거 조회의 운영 차트 배지는 현재 합성 시나리오와 독립적으로 '과거 원본 조회'를 표시한다.

후보 재생 이동
- 진단 검토 표·알림 타임라인·상세 패널에서 서버 jump_event를 호출한다.
- 서버가 현재 시연 범위와 독립적으로 첫 감지30초 전부터 새 세션을 설정하고 자동 재생한다.
- 응답의 모듈을 선택하고 설비분석으로 이동하며 날짜/집계 필터를 초기화한다.
- 유형에 따라 역률/전류/무효전력/유효전력의 관련 센서 탭을 선택한다.
- replay.highlight의 end는 exclusive로 사용한다. 상세 원본 archive의 마지막 관측 end는 +5초로 표시 범위에 포함한다.

색상·근거
- 정상: primary #2563eb, S상 #0284c7, T상 #1e40af. 이상 후보: #dc2626.
- 센서 차트의 후보 점·선과 선택 후보 구간을 빨강으로 표시한다.
- 규칙/AE/IF 점수는 실제 score > threshold인 점·선·구간만 빨강으로 표시하며 잠근 임계선은 붉은 점선이다.
- 후보 음영과 단일 모델의 임계값 초과는 실제 고장 확정 또는 고장 확률을 의미하지 않는다.
- 알림 근거는 한국어 주요값 최대4개를 요약하고 전체 원문은 접어서 제공한다.
